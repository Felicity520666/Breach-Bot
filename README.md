# Breach Bot

## About this project

Hi there! 👋 This is Breach Bot, an interactive Python chatbot for learning about the
2011 PlayStation Network data breach. It explains what happened, describes
Sony's response, and connects the incident to the CIA triad: confidentiality,
integrity, and availability. It also shares my personal reflection on this topic!
💞
## Features

- Greets the user by name
- Asks for the current year and calculates how long ago the breach occurred
- Explains the breach and Sony's response
- Shares a reflection and practical cybersecurity advice
- Uses simple menus so users can choose what to learn about

## Language used

- Python 3

## How to run

Open a terminal in the project folder and run:

```bash
python3 main.py
```

Follow the prompts and enter the letter beside your chosen topic. Enter `c` in
the first menu to continue to the reflection section, then enter `d` in the
second menu when you are finished.
